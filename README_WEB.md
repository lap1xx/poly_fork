# Poly-ARB Web — локальный радар

Веб-интерфейс для бота Poly-ARB. Работает поверх существующего `bot_live.py`
и `polyarb_v4.py`, не меняя их логику.

## Установка (один раз)

1. Убедись что Chrome + chrome_bridge + bot_live работают как раньше
2. Скопируй эти файлы в папку проекта рядом с `polyarb_v4.py`:
   - `install_web.bat`
   - `polyarb_v4_patch.py`
   - `bot_live_patch.py`
   - `web_app.py`
   - `templates/index.html`
   - `static/style.css`
   - `static/app.js`
3. Запусти:

```

install_web.bat

```

Скрипт установит `fastapi`, `uvicorn`, пропатчит ядро и `bot_live`.

## Запуск

Обычно — как раньше:

```

Окно 1: python chrome_bridge.py
Окно 2: python -B bot_live.py

```

`bot_live.py` автоматически поднимет `web_app.py` на порту 8080.
Открой **http://localhost:8080** в браузере.

Если хочешь запустить `web_app` отдельно (для отладки):

```

python -B bot_live.py --no-web
python web_app.py

```

## Что появилось

- **Дашборд «Сегодня»** — прибыль, оборот, ROI, кольцо прогресса
- **Активные вилки** — карточки, отсортированы по ROI
- **Фильтры** — спорт + минимальный ROI
- **Редактор сделки** — открывается по клику на карточку
  - правь кэфы PM и BB, ставки пересчитываются автоматически
  - кнопки «Открыть на PM» / «Открыть на BB»
  - кнопка «Скрыть» (только текущая сессия)
- **Мои сделки** — журнал сохранённых сделок (в `trades.jsonl`)
- **Экспорт CSV** — скачивает `arbs.csv`

## Файлы, которые создаёт web_app

- `arbs_live.json` — снапшот активных вилок (пишет `polyarb_v4.py`)
- `trades.jsonl` — сохранённые сделки из редактора
- `hidden_slugs.json` — скрытые слаги (переживают перезапуск)

## Если что-то сломалось

**`install_web.bat` ругается: "Якорь не найден"**
Значит структура `polyarb_v4.py` или `bot_live.py` отличается от ожидаемой.
Скинь текущий `main()` — поправим патч.

**Порт 8080 занят**
Поменяй в `web_app.py` последнюю строку:
```python
uvicorn.run(app, host="127.0.0.1", port=8081, ...)
```

**Открывается, но список пустой**

- Проверь что `polyarb_v4.py` реально нашёл вилки (в окне bot_live должны быть `[+] ARB FOUND`)
- Проверь что файл `arbs_live.json` создаётся в папке проекта
- Если нет — патч не применился, запусти `python polyarb_v4_patch.py` снова

**WebSocket отваливается**
Проверь консоль браузера (F12) — должна быть ошибка соединения.
Попробуй открыть `http://127.0.0.1:8080` вместо `localhost:8080` (иногда IPv6 мешает).
