## Что исправлено

- **Расчёты и валидация:** неfinite/неположительные входные odds, банк, комиссия и проскальзывание больше не проходят в расчёт. Пересчёт Polymarket учитывает, что рублёвая ставка сначала конвертируется в доллары и shares; курс не ошибочно умножает сами odds. Сигнал отклоняется, если свежей глубины стакана не хватает на весь расчётный объём.
- **Курс USD/RUB:** при сбое ЦБ используется только валидный положительный курс из `config.json`; если такого нет — сканер прекращает расчёт вместо подстановки `1:1`.
- **Polymarket feed:** список токенов можно обновлять без перезапуска процесса; поток переподключается с актуальной подпиской. Некорректные уровни стакана с `NaN`, бесконечностями и ценой вне `0–1` отбрасываются.
- **Сигналы:** дедупликация использует пару исходов и источник; `--alert-gap` ограничивает частоту изменений и выдаёт напоминания для сохраняющегося сигнала. За интервал подавления последнее изменение не теряется. Snapshot выбирает лучший ROI для каждого slug детерминированно.
- **Сопоставление букмекера:** неизвестный исход больше не назначается `home/away` только по порядку элементов.
- **История и статистика:** sampler истории корректно останавливается и перезапускается; фильтрация ISO-времени учитывает часовые пояса. Сигналы сканера не маркируются как исполненные сделки.
- **Локальная панель:** backend сообщает возраст snapshot и помечает устаревшие данные. Настройки, ручной журнал и размер запроса стакана валидируются; JSON-настройки сохраняются атомарно; CSV использует корректное quoting и защиту от spreadsheet-formula injection. Изменяющие запросы и WebSocket ограничены локальным same-origin доступом. Поля из snapshot экранируются перед HTML-вставкой.
- **Запуск:** установка изолирована в `.venv`. `start_all.bat` запускает только локальный dashboard на `127.0.0.1:8080`; он не убивает процессы, не поднимает браузерный CDP bridge и не запускает scanner автоматически.

## Применение patch

Patch предназначен для точного базового commit выше. Сначала сохраните копию репозитория, затем в его корне выполните:

```bash
git apply --check poly_fork_fix.patch
git apply poly_fork_fix.patch
```

Новые локальные тесты лежат в `tests/test_local_fixes.py`. Patch и архив подготовлены отдельно; ничего не отправлялось в GitHub.
